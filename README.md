# Periódika

Tabela periódica interativa para aulas de Química do Ensino Médio, com massa atômica, número de oxidação (NOX) e distribuição eletrônica completa de cada elemento.

Autoria: Prof. Héverson Dias Pedroza.

## Como usar

Abra o site publicado pelo GitHub Pages ou o arquivo `index.html` em qualquer navegador. Não há instalação nem dependências, exceto a fonte Figtree, carregada do Google Fonts.

## Fonte dos dados

Massas atômicas conforme CIAAW (2024), arredondadas para fins didáticos. Na lista de NOX, o negrito indica os números mais comuns e frequentes no Ensino Médio e no ENEM.
